您可以在此页面上找到有关您的套餐和名额使用情况的信息。

## Label Studio Enterprise

### 已使用名额

您可以在此处查看名额数量与活跃用户数量的对比。

每个组织在其许可证中都有一定数量的 Label Studio 名额。要增加名额，请联系您的 HumanSignal 客户代表。

### 许可证信息

此部分包含有关您 Label Studio 许可证的一般信息，例如颁发时间和到期时间。

还包括以下使用信息：

<dl>
<dt>项目</dt>
<dd>

**Cloud/SaaS：** 属于您当前组织的每个项目，无论其状态（草稿/已发布）或工作区（包括沙盒项目）。

**本地部署：** 服务器上的所有项目，无论状态或工作区。
</dd>

<dt>结果</dt>
<dd>

您的组织在所有项目中创建的标注区域（结果）总数。一个结果是标注结果数组中的一项——边界框、文本片段、区域之间的关系等。
</dd>
</dl>

### 安全设置

只有组织 Owner 可以更新这些设置。

<dl>
<dt>会话超时策略</dt>
<dd>

| 字段                         | 描述    |
| ---------------------------- | ------------ |
| **最大会话空闲时间（分钟）**  | 用户可以处于空闲状态的分钟数。如果超过此限制，他们将在下次触发请求时自动注销。<br>任何触发后端请求的交互（触发 API 调用的点击、保存、轮询等）都会重置此计时器。 |
| **活动最大间隔时间（分钟）**  | 绝对会话生命周期。无论活动情况如何，会话从登录开始不能超过此分钟数；一旦达到，用户必须重新认证。 |

</dd>

</dd>
</dl>

### 邮件通知设置

决定在[**账户和设置**页面](user_account)中可用的邮件偏好设置。

请注意以下事项：

* 新用户的邮件通知偏好默认启用。
* 如果您在此处禁用某项通知，该偏好将从其**账户和设置**页面中隐藏，并对您组织中的所有用户屏蔽。
* 如果您重新启用某项通知，该偏好将重新出现在其**账户和设置**页面中，并恢复为在组织级别禁用之前用户所设置的状态。

### Enterprise 计费常见问题

查找与计费相关的常见问题解答。

#### 如果我的套餐处于非活跃状态会怎样？

如果您的 Label Studio Enterprise 订阅到期或被取消，您将无法再进行标注、审核标注或向组织添加新用户。您仍然可以登录并导出已完成的标注。

#### 如果我的活跃用户过多会怎样？

如果您的活跃用户数超过订阅允许的数量，您需要为 Label Studio Teams 订阅购买额外的名额。用户一旦被分配角色即计为活跃用户。已邀请但尚未接受邀请的用户显示为"未激活"，不计入名额限制。

## Label Studio Starter Cloud

Label Studio Starter Cloud 有**使用情况与计费**页面，显示有关您的订阅以及已使用名额数量的信息。

!!! note
    只有组织 Owner 可以访问使用情况与计费页面。

订阅有两个组成部分：

* **基础订阅** - 这是您对 Label Studio Starter Cloud 的访问权限，包含 1 个名额。
* **额外名额** - 您可以根据需要购买最多 11 个额外名额（总计 12 个）。

### 管理名额

#### 添加名额

作为 Owner，转到**组织 > 使用情况与计费**。点击**管理名额**并增加您的名额数量。

添加名额时，费用按比例计算并反映在您的下一张发票上。一个组织最多可以有 12 个名额。

#### 移除名额

在移除名额之前，您必须停用其关联的用户。活跃用户数不能超过名额数量。

要停用用户，请转到**组织 > 成员**页面，将用户的角色设置为**已停用**。

然后点击**管理名额**并减少您的名额数量。

移除名额时，费用按比例计算并反映在您的下一张发票上。

### Starter Cloud 计费常见问题

#### 如何取消？

作为 Owner，转到**组织 > 使用情况与计费**并点击**取消**。

取消后，您的账户在已付费的计费周期结束前仍然保持活跃。在此期间，您可以完全访问 Label Studio Starter Cloud 的功能。

但是，取消后，您无法添加用户名额。如果需要的用户数超过当前名额允许的数量，您必须重新激活订阅。

当计费周期结束时，您将保留对 Label Studio 的访问权限，可以下载数据。但是，您将无法导入新数据、标注现有数据或创建新项目。

#### 如何续费？

如果您没有取消订阅，订阅将在计费周期结束时自动续费。
