## 前提条件

* 一个用于大语言模型的 [API 密钥](prompts_keys)。
* 一个满足[下述条件](#创建提示)的项目。

## 创建提示

在提示页面，点击右上角的**创建提示**，然后填写以下字段：

<div class="noheader rowheader">

| | |
| --- | --- |
| 名称 | 输入提示的名称。 |
| 描述 | 输入提示的描述。 |
| 目标项目 | 选择要使用的项目。如果没有符合条件的项目，您将看到一条错误消息。<br>请参阅下面的说明。<br><br>选择项目后，将显示有关标注配置的附加信息。这包括应用提示时将使用的分类类别。 |

</div>

!!! note 符合条件的项目
    目标项目必须满足以下条件：
    * 您必须有权访问该项目。如果您是经理角色，需要被添加到项目中才能访问。
    * 该项目不能位于您的个人沙盒工作区中。
    * 虽然连接了机器学习后端的项目仍会出现在符合条件的项目列表中，但我们不建议将提示与机器学习后端一起使用，因为这可能会干扰评估提示时准确性和得分的计算方式。
