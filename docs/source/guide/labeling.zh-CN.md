使用开源数据标注工具 Label Studio 标注和注释您的数据。在[设置项目](setup_project.html)、[标注界面](setup.html)并[导入数据](tasks.html)之后，您就可以开始标注和注释数据了。

1. 在 Label Studio 中打开项目，也可以选择[筛选或排序数据](manage_data.html#Filter-or-sort-project-data)。
2. 点击**标注所有任务**来[开始标注](#开始标注)。
3. 使用[键盘快捷键](#使用键盘快捷键加速区域标注)或鼠标来标注数据并提交您的注释。
4. 按照项目说明进行标注，并决定是否跳过任务。
5. 点击项目名称返回数据管理器。

您还可以[与其他标注人员协作](#与协作人员一起标注)，以提高标注数据的质量。


## 开始标注

某些标注任务可能较为复杂，例如包含文本、图像和音频数据对象的综合数据集和标注任务，或在标注任务上创建注释之间的关系。本节包含如何执行更复杂标注任务的指导，例如带关系标注、重叠区域标注、选定任务标注或更改标签。

### 选择要标注的任务
在项目中，点击**标注所有任务**开始标注所有任务。如果要按照数据管理器中筛选和排序的顺序标注任务，请选择**按显示顺序标注任务**。

您也可以从项目数据管理器视图中点击特定任务，在**快速查看**或**预览**中标注该任务，但提交注释后不会自动看到标注队列中的下一个任务。

您还可以选中特定任务旁的复选框，然后点击**标注 $n 个任务**来标注选定数量的任务。例如，为 5 个不同任务勾选复选框，然后点击**标注 5 个任务**来仅标注这 5 个任务。

!!! note
    标注任务时，不应同时在两个标签页中打开标注流（即点击**标注所有任务**）。这可能导致您收到同一任务两次，从而绕过处理标注人员重叠的项目设置。

### 在数据中标注区域
通过添加区域来注释数据的某个部分。

1. 选择要应用到该区域的标签。对于某些配置，可以跳过此步骤。
2. 点击文本、图像、音频或其他数据对象，将标签应用到该区域。您的更改会自动保存。
3. 点击**提交**以提交已完成的注释并进入下一个任务。

### 标注重叠区域
当您使用边界框和其他图像分割任务进行标注时，或为 NLP 和 NER 标注高亮文本时，您可能需要标注重叠区域。为此，可以在注释后隐藏已标注的区域。

1. 选择要应用到该区域的标签。
2. 绘制边界框或高亮要标注的文本。
3. 在**区域**或**标签**侧边栏中，找到并选择已标注的区域，点击眼睛图标隐藏该区域。
4. 或按 cmd 或 ctrl 键在现有**区域**或**标签**上绘制（注意：此方法不适用于关键点）。
5. 选择要应用到重叠区域的下一个标签。
6. 绘制边界框或高亮要标注的文本。
7. 继续隐藏和标注区域，直到完成该任务的注释。如果需要，选择**区域**旁边的眼睛图标来隐藏然后显示任务上所有已标注的区域，以确认最终结果。
8. 点击**提交**以提交已完成的注释并进入下一个任务。

### 选择多个区域
标注时可以同时选择多个区域进行批量修改。

1. 创建多个区域后，按 `ctrl` 键并点击要选择的每个区域。您可以在标注对象上或在**区域**侧边栏中选择区域。在**区域**侧边栏中选择一系列区域时，点击列表中要选择的第一个区域，然后按住 `Shift` 点击列表中要选择的最后一个区域。
2. 选择区域后，可以为所有选中的区域应用标签或删除它们。
3. 点击已选中的区域或按 `u` 取消选择。

### 复制区域
您可以复制区域以创建多个相同大小的多边形、矩形或椭圆。

1. 选择要复制的区域。
2. 按 `ctrl + d` 复制区域，或依次按 `ctrl + c` 和 `ctrl + v` 复制并粘贴区域。复制的区域会出现在与被复制区域完全相同的位置。如果您使用 Mac 键盘，请使用 `cmd` 而非 `ctrl`。
3. 点击箭头工具，然后移动和调整新创建区域的大小。

### 更改标签
您可以更改现有区域的标签。

1. 在对象上或通过**区域**侧边栏，选择已标注的区域，例如文本片段、边界框、图像分割、音频区域或其他区域。
2. 选择新标签。标签更改会自动保存。
3. 点击**提交**以提交已完成的注释并进入下一个任务。

### 删除已标注的区域
如果需要，您可以删除已标注的区域，如边界框或文本片段。

1. 在对象上或在**区域**侧边栏中选择已标注的区域。
2. 按 Backspace 键，或转到**结果**面板并删除选中的注释。

### 删除注释
标注任务后，您可以点击垃圾桶按钮删除该任务上的注释。如果尚未保存注释，点击 `X` 图标重置任务并清除您的标注操作。

您也可以从项目页面删除任务上的所有注释。请参阅[删除任务或注释](manage_data.html#Delete_tasks_or_annotations)。

### 在注释之间添加关系
您可以在两个结果之间创建带有方向和标签的关系。要向方向添加标签，您必须设置包含关系标签的标注配置。有关更多信息，请参阅标签文档中的[带标签的关系](/tags/relations.html)。

1. 选择要关联到另一个注释的注释区域。如果要创建基于方向的关系，请先选择第一个。
2. 在**结果**侧边栏的**区域**部分，点击看起来像超链接图标的**创建关系**按钮。
3. 选择第二个注释区域以完成关系。

<br>
<img src="../images/relation.png" class="gif-border">
<i>图 1：在注释之间添加关系 </i>

关联两个注释区域后，您可以在**结果**侧边栏的**关系**部分修改关系。
- 要更改关系方向，点击两个相关区域之间的方向按钮。
- 要向指示两个注释之间关系的方向箭头添加标签，点击两个相关区域旁边的垂直省略号按钮以添加预定义的标签。您必须有一个[包含关系的标签配置](/tags/relations.html)才能执行此操作。

### 退出标注流程
当标注人员尚未完成注释工作但想退出标注流程时（例如暂停其注释的[耗时](/guide/task_format.html#Relevant-JSON-property-descriptions)计算），他们可以点击**提交**旁边的下拉菜单，然后选择**提交并退出**（或**更新并退出**）。这将提交当前注释并将其重定向到项目页面。

如果标注人员尚未完成注释，他们可以检查其草稿是否已保存在历史面板中，然后导航到项目页面以停止[耗时](/guide/task_format.html#Relevant-JSON-property-descriptions)计算的运行。

## 与协作人员一起标注

在 Label Studio 和 Label Studio Enterprise 中，您都可以与协作人员一起标注任务。当有人在执行注释时，任务会被锁定，以免您意外覆盖其他标注人员的注释。当其他标注人员完成该任务后，如果每个任务的最低注释数设置为大于 1，该任务就会出现在您的标注队列中。默认情况下，任务只需一人标注。

<div class="enterprise-only">

如果您使用 Label Studio Enterprise 并希望多个标注人员标注任务，请<a href="setup_project.html">更新项目设置</a>。更新每个任务所需的最低注释数后，标注人员可以使用标注流工作流来标注其任务。

</div>

如果即使最低注释数设为 1，您仍想多次标注任务，请按以下步骤操作：

当最低注释数设为 1 时多次标注任务，请按以下步骤操作：
1. 在项目的数据管理器中，点击一个任务打开快速标注视图。
2. 点击任务注释 ID 旁边的 `+` 图标打开一个注释标签页。
3. 标注该任务。
4. 点击**提交**保存您的注释。
5. 在数据管理器中点击下一个任务，打开该任务的快速标注视图，重复步骤 2-4。


## 使用交互式预注释执行 ML 辅助标注

如果您设置了机器学习后端以[获取交互式预注释](ml.html#Get-interactive-preannotations)，您可以在标注时选择是否使用这些预测。

1. 开始标注后，您可以启用**自动注释**来查看并使用智能选项来分配标签、绘制形状、遮罩或分配关键点。在使用智能选项在图像上绘制，或标注文本或 HTML 片段后，ML 后端会返回预测。
2. 对于图像标注，启用自动注释后您可以选择是否**自动接受注释建议**。如果自动接受注释建议，区域会自动显示并立即创建。如果不自动接受建议，区域会出现，但您可以手动拒绝或批准它们，可以单独处理也可以一次性处理。预测的文本区域会自动接受。

## 高级图像标注

如果您想进行高级图像标注，请参考以下示例和指南。

### 为图像注释添加多种类型的区域
您可以为图像注释添加多种类型的区域。您可以添加以下任何类型：
- 矩形
- 椭圆
- 关键点
- 多边形
- 画笔遮罩

要为图像注释添加不同类型的区域，请参考以下示例。

使用以下示例为您的标注界面创建自定义模板：

```xml
<View>
  <Image name="image" value="$image" />
  <Rectangle name="rect" toName="image" />
  <Ellipse name="ellipse" toName="image" />
  <KeyPoint name="kp" toName="image" />
  <Polygon name="polygon" toName="image" />
  <Brush name="brush" toName="image" />
  <Choices name="choices" toName="image">
    <Choice value="yes"></Choice>
    <Choice value="no"></Choice>
  </Choices>
  <Labels name="labels" toName="image" fillOpacity="0.5" strokeWidth="5">
    <Label value="building" background="green"></Label>
    <Label value="vehicle" background="blue"></Label>
  </Labels>
</View>
```
此示例使矩形、椭圆、多边形、关键点和画笔遮罩可供标注人员使用，同时提供图像分类选项 yes 和 no，以及区域标签 building 和 vehicle。

### 更快速的图像标注
只需两次点击即可为图像添加矩形或椭圆，或双击创建多边形、矩形或椭圆。

如果在创建多边形时误点图像上的某个点，只需双击即可删除错误点并继续创建区域。多边形上必须至少有三个点才能删除点。

### 创建不带标签的区域
在注释图像时，您可以创建区域而不应用标签。

1. 使用上面[为图像注释添加多种类型的区域](#为图像注释添加多种类型的区域)中提供的示例创建自定义模板。
2. 在标注工具栏中选择要使用的工具。您只需要为第一个任务执行此操作。
3. 通过双击或点击并拖动创建边界框，或点击构造多边形所需的点来创建区域。
4. 在侧边栏中或在图像上选择已创建的区域。
5. 选择要应用到该区域的标签。
6. 对要创建的任何区域重复这些步骤。

这对于两步标注非常有用，即让一位标注人员创建区域，另一位标注人员为区域分配标签。

### 擦除画笔遮罩标签
如果在使用画笔遮罩标注时出错，可以擦除错误部分。在擦除画笔遮罩的任何部分之前，必须先在侧边栏中选择一个画笔区域。

如果要完全删除一个区域重新开始，请删除该区域而不是擦除。擦除区域并不会将其删除。

**区域分组或排序**

您可以使用下拉列表中的以下功能对区域进行分组或排序。

- **手动分组**：手动区域分组（拖放）。选择此选项时，您可以将区域拖放到其他区域中，创建树形结构，并将区域组合在一起。
- **按工具分组**：选择此选项时，工具（矩形、多边形）会被添加。您可以使用包含所有这些工具的模板，按生成区域的工具对区域进行分组。
- **按标签分组**：选择此选项并绘制区域后，您将看到一个文本标签，可以展开它。文本标签仅显示与此功能相关的文本。

!!! warning
    **按标签分组**和**按工具分组**选项不适用于多图像场景或多标签类型场景；只有**手动分组**选项可用于此模式。

**区域的预测指示**
此功能显示区域是否由 ML 模型创建。

**关系列表**
一个区域属于另一个区域。这通常用于 NLP 类型的文本。例如，将城市名称视为区域 1，将区名视为区域 2。现在，在关系列表层次结构中，您将把区域 2 放在区域 1 下面。关系列表可以是单向或双向的。您可以将一个区域嵌套到另一个区域中。

**在另一个边界框上绘制边界框**

!!! attention "重要"
    在为图像创建边界框注释时，不能在另一个边界框内部开始绘制新边界框，因为这样只会拖动第一个框。相反，当选择矩形工具时，它会在图像前面创建一个新的边界框。

要在上方创建边界框，您可以使用两种方式：

1. 按矩形工具（R）。

!!! note
    此选项并非始终可见。

2. 标注一个边界框，然后在其内部标注另一个边界框。

现在，当矩形工具未选中时，您应该能够拖动。请记住，当矩形工具选中时，即使在另一个矩形之上，您也可以创建矩形。

或者

1. 按 CTRL 键并开始在另一个边界框上绘制边界框。
