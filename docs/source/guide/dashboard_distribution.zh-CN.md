**分析 > 标签分布**仪表盘显示项目中标注值和预测值的分布情况。使用它来识别标签不平衡、比较标注员和模型输出，并深入查看标签值背后的任务。

![标签分布仪表盘截图](/images/analytics/label-dist.png)

## 按用户角色访问

| 用户角色 | 访问限制 |
|-----------|---------------------|
| **Owner** 和 **Admin** | 可以查看**标签分布**仪表盘并筛选所有项目。 |
| **Manager** | 可以查看**标签分布**仪表盘，但只能筛选和查看自己作为成员的项目。 |
| **Reviewer** 和 **Annotator** | 无法访问**标签分布**仪表盘。<br/><br/>当他们打开**分析**时，会被重定向到[成员绩效仪表盘](dashboard_annotator)，在那里他们只能看到自己的标注和审核历史。 |

## 按维度的标签分布

仪表盘按标注维度对结果进行分组。维度可以来自传统的标注配置控件标签，也可以来自 Interface 输出，例如 ReactCode 或 CustomInterface 字段。

每个受支持的维度都有一个卡片，包含：

- **平均一致性**：当有足够的数据来比较标注、预测或基准真相时，该维度的一致性。
- **标签分布图**：一个分组水平条形图，比较标注和预测中的值。
- **标签明细表**：标注和预测中每个值的计数。

![标签分布仪表盘截图](/images/analytics/label-dist-charts.png)

## 标签明细表

标签明细表显示所选维度的每个值，加上一个**合计**行。

| 列 | 描述 |
|--------|-------------|
| **标签** | 标签或值的名称。最后一行显示所有值的总计。 |
| **来自标注** | 该值在标注中出现的次数。 |
| **来自预测** | 该值在预测中出现的次数。 |

**来自标注**和**来自预测**列中的值可以链接到数据管理器，并应用所选项目、维度、值和来源的筛选条件。使用这些链接来检查底层的任务、标注或预测。

![标签分布表格截图](/images/analytics/label-dist-tables.png)

## 受支持的维度

标签分布支持具有有限值集的维度，包括：

- 标签控件，如 `<Labels>`、`<RectangleLabels>` 以及其他基于标签的控件。
- 选择控件，如 `<Choices>`。
- 具有有限嵌套选项的分类控件。
- 枚举类型的 ReactCode 和 CustomInterface 维度。
- 其他可以表示为已知值集的有限标量维度。

不具有有限值集的维度不会作为标签分布显示。这包括自由文本、任意数值或日期值、对象、数组以及未在维度 schema 中声明的值。

!!! note
    如果某个维度不受支持，仪表盘应显示其不受支持，而不是渲染空图表。这有助于区分"没有数据"与无法安全地作为标签分布汇总的数据。
