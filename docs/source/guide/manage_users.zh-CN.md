用户管理是数据标注工作流中的关键组成部分。

数据标注通常涉及敏感或专有信息，控制谁有权访问这些数据对于保护数据免受未授权访问或滥用至关重要。通过实施完善的用户管理，你可以确保只有经过授权的用户账户才能访问特定的数据集。这在处理敏感数据的环境中尤为重要，例如医疗记录或个人信息，这些环境可能适用 GDPR 或 HIPAA 等数据隐私法规。

此外，用户管理可以简化工作流程并提高数据标注项目的效率。由于不同用户可以拥有不同的角色，你可以定制项目，使每个用户都拥有完成其任务所需的适当工具和数据访问权限。这不仅提高了数据标注过程的准确性和一致性，还最大程度地减少了因未授权访问或修改而导致的错误或冲突风险。

Label Studio Enterprise 用户管理选项包括：

* **基于角色的访问控制（RBAC）**：角色决定了用户拥有的访问级别以及他们能够完成的操作。有关这些角色的更多信息，请参阅[角色与权限](admin_roles)。有关分配角色的信息，请参阅[管理用户账户](admin_manage_lse)。

* **通过角色实现用户工作流**：你还可以使用角色为用户设计标注工作流。例如，你可以使用项目设置为审核员和标注者配置分别显示的说明。有关更多信息，请参阅[项目设置](setup_project)。

* **用户活动监控**：管理员可以通过活动日志跟踪用户活动，例如谁标注了什么数据以及何时标注。有关更多信息，请参阅[活动日志](admin_logs)。

* **项目和工作区**：你可以通过工作区和项目成员资格来控制项目的可见性。拥有管理者、标注者或审核员角色的用户必须被添加为成员才能查看工作区或项目。工作区用于组织项目，成员资格会级联到工作区内的项目。有关更多信息，请参阅[项目设置](setup_project)。

* **SSO/SAML 与 SCIM 集成**：对于使用单点登录（SSO）或跨域身份管理系统（SCIM）的企业，Label Studio Enterprise 允许在组织级别和项目级别将组映射到角色。有关更多信息，请参阅 [SSO 和 SAML 设置](auth_setup)以及 [SCIM2 设置](scim_setup)。

* **自定义与可编程性**：你可以通过 API 端点以编程方式为用户分配角色并管理用户账户，从而实现自动化以及与外部系统的集成。有关更多信息，请参阅我们的 [API 参考文档](/api/#tag/Users)。
