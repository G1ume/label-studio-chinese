工作空间可以帮助您在不同生命周期阶段或用例中组织、分类和管理项目：

* 使用工作空间对相关项目进行分组和分类。
* 使用工作空间简化项目成员管理。当用户被添加为工作空间的成员时，他们将可以访问该工作空间内的所有项目。他们对项目的权限取决于他们的[用户角色](admin_roles)。
* 使用工作空间归档项目。


## 创建工作空间

!!! note
    要创建新的工作空间，您的用户角色必须是 Owner、Administrator 或 Manager。


1. 在 Label Studio 中，点击右侧菜单中 **Workspaces** 旁边的加号图标：

    ![添加按钮截图](/images/click-plus-sign.png)

2. 提供工作空间的名称，并可选择一种颜色。
3. 点击 **Save**。

您现在可以开始在工作空间内[创建项目](setup_project)。

!!! info Tip
    您也可以通过从不同工作空间复制现有项目来创建项目。或者，您可以更新[项目设置](manage_projects#Move-projects-between-workspaces)将项目从一个工作空间移动到另一个工作空间。

## Sandbox 工作空间

每个用户都有一个个人 Sandbox 工作空间，可用于试验项目设置并熟悉 Label Studio。只有您自己可以看到 Sandbox 中的项目。

您可以使用 Sandbox 配置项目并测试设置。然后当您准备好时，可以将项目移出 Sandbox，移到其他用户可以访问的工作空间中。

## 添加或移除工作空间成员

当用户被添加到工作空间时，他们会自动获得该工作空间内所有项目的成员资格。他们在项目中能够看到的操作和信息取决于他们的用户角色。

1. 从工作空间中，点击右上角的 **Manage Members**。
2. 使用搜索功能找到您要添加到工作空间的用户。
3. 选中其姓名旁边的复选框，点击 `>` 箭头将他们添加进来。点击反向箭头 `<` 移除成员。
4. 点击 **Save**。

用户在被添加到工作空间时不会收到通知。工作空间会在他们登录 Label Studio 或刷新页面时出现。

## 工作空间权限

用户角色在组织级别设置。有关更多信息，请参阅[用户角色和权限](admin_roles)。

* **Owner 和 Administrator**——这些用户可以看到所有工作空间，即使他们尚未被添加为成员。

    他们还可以看到这些工作空间中未发布的项目。唯一的例外是您的 Sandbox 工作空间，只有您自己可以看到。
* **Manager**——Manager 可以创建工作空间。但组织中的其他 Manager 无法查看该工作空间，除非他们被添加为成员。

    一旦被添加，Manager 可以看到工作空间内的所有项目，包括未发布的项目。
* **Annotator**——在被添加为成员之前无法查看工作空间。

    一旦被添加，他们可以看到所有项目的卡片，但在项目发布并且他们有任务需要标注之前，无法进入标注流。
* **Reviewer**——在被添加为成员之前无法查看工作空间。

    一旦被添加，他们可以看到所有项目的卡片，但在项目发布并且他们有任务需要审核之前，无法访问项目。

## 编辑工作空间

您可以归档、删除、重命名工作空间，以及为工作空间选择不同的颜色。点击工作空间名称旁边的齿轮图标查看您的选项：

![工作空间菜单截图](/images/project/workspace-edit-modal.png)

要访问这些操作，您的用户角色必须是 Owner、Administrator 或 Manager。

## 归档工作空间

为了减少工作空间侧边栏的杂乱，您可以归档工作空间使其不在视图中显示，从而让您轻松找到优先级高的标注项目。您仍然可以完全访问已归档的工作空间，并且可以随时取消归档。

点击工作空间名称旁边的齿轮图标，或点击工作空间旁边的溢出菜单，选择 **Archive**：

![工作空间菜单截图](/images/project/workspace-dropdown-menu.png)

### 查看已归档的工作空间和取消归档

要查看已归档的工作空间，请展开项目页面侧边栏底部的已归档工作空间菜单。

![已归档工作空间选项截图](/images/project/workspace-archive-expand.png)

在这里，您可以点击工作空间名称旁边的齿轮图标，或点击工作空间旁边的溢出菜单，选择 **Unarchive**：

![已归档工作空间选项截图](/images/project/workspace-unarchive-menu.png)


## 删除工作空间

您只能删除没有项目的工作空间。如果您想删除一个工作空间，请先[删除项目](manage_projects#Delete-projects)或[将它们移动](manage_projects#Move-projects-between-workspaces)到另一个工作空间。

一旦所有项目都被删除，点击工作空间名称旁边的齿轮图标，然后点击 **Delete**。
