## 通用设置

使用这些设置来指定项目的基本信息。

| 字段          | 描述    |
| ------------- | ------------ |
| **项目名称** | 输入项目的名称。 |
| **描述**       | 输入项目的描述。 |
| **颜色**      | 您可以为项目选择一种颜色。在项目页面上查看时，该项目将以此颜色高亮显示。 |
| **任务采样**     | <ul><li><strong>顺序采样</strong>——任务按照在数据管理器中的显示顺序呈现给标注者</li><li><strong>随机采样</strong>——任务以随机顺序显示。</li></ul> |


## 标注界面

标注界面是项目的核心配置点。它决定了任务如何呈现给标注者。

有关设置标注界面的信息，请参阅[标注配置](setup)。

## 标注

<dl>

<dt>标注说明</dt>

<dd>

指定在用户标注任务时向用户显示的说明。此字段支持 HTML 格式。

启用**标注前显示**可在用户进入标注流时显示弹窗消息。

如果禁用，用户需要点击标注界面底部的**显示说明**操作。

</dd>

<dt>实时预测</dt>

<dd>

如果您连接了机器学习后端或模型，可以使用此设置来确定是否应使用模型的预测对任务进行预标注。有关更多信息，请参阅[将 Label Studio 集成到您的机器学习流程中](ml)。

使用下拉菜单选择预测来源。例如，您可以选择[已连接的模型](#模型)或一组[预测](#预测)。

</dd>

</dl>

## 模型

点击**连接模型**将机器学习（ML）后端连接到您的项目。有关连接模型的更多信息，请参阅[机器学习集成](ml)。

您有以下配置选项：

| 字段          | 描述    |
| ------------- | ------------ |
| **在标注提交时启动模型训练**         | 每次创建或更新标注时，触发已连接的机器学习后端启动训练过程。<br /><br />这是[主动学习循环](https://docs.humansignal.com/guide/active_learning)的一部分，在该循环中，模型可以随着新标注添加到数据集中而持续改进。启用此设置后，将调用机器学习后端的 `fit()` 方法，使模型能够从最新的标注中学习，并可能改进其对后续任务的预测。   |
| [**交互式预标注**](ml#interactive-pre-annotations)         | （在创建或编辑模型连接时可用）<br /><br />启用此选项可让模型通过提供实时预测或建议来辅助标注过程，当标注者处理任务时实时响应。<br /><br />换句话说，当您与数据交互（例如，在图像上绘制区域、高亮文本或向大语言模型提问）时，机器学习后端会接收这些输入并基于此返回预测。   |


已连接模型旁边的溢出菜单提供以下操作：

| 操作          | 描述    |
| ------------- | ------------ |
| **开始训练**         | 手动启动训练。如果您希望控制模型训练的时间，例如在收集到一定数量的标注后或按特定时间间隔进行训练，可以使用此操作。  |
| **发送测试请求**         | （可从已连接模型旁边的溢出菜单中获取）<br /><br />用于故障排除并向已连接的模型发送测试请求。   |
| **编辑**         | 编辑模型名称、URL 和参数。有关更多信息，请参阅[将模型连接到 Label Studio](ml#Connect-a-model-to-Label-Studio)。 |
| **删除**         | 移除与模型的连接。 |

## 预测

在此处，您可以查看在执行数据管理器的**获取预测**操作时已导入或已生成的预测。有关更多信息，请参阅[将预标注数据导入 Label Studio](predictions)。

## 云存储

在此处将 Label Studio 连接到云存储提供商：

* **源云存储**——项目源数据的保存位置。当您同步源存储时，Label Studio 会获取待标注的数据。
* **目标云存储**——标注结果的保存位置。当您同步目标存储时，标注结果将从 Label Studio 发送到目标存储位置。

有关更多信息，请参阅[从外部存储同步数据](storage)。

## Webhooks

您可以使用 Webhooks 集成第三方应用程序。有关更多信息，请参阅[在 Label Studio 中设置 Webhooks](webhooks) 和我们的[集成目录](https://labelstud.io/integrations/)。

## 危险区域

在此处，您可以访问可能导致数据丢失的操作，请谨慎使用。

* **删除所有标签页**

    如果数据管理器无法加载，删除所有数据管理器标签页可能有所帮助。
* **删除项目**

    删除项目将永久移除 Label Studio 中的所有任务、标注和项目数据。
