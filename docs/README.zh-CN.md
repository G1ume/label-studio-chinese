# Label Studio 文档

## 使用和部署 Hexo

### 安装依赖

```shell
npm install
```

### 启动开发服务器

```shell
npm run server
```

启动本地服务器。默认访问地址为 http://localhost:4000/。

### 部署文档

```shell
npm run publish
```

## 使用 Hexo 在本地部署文档
要在本地机器上使用 Hexo 部署文档，请按照以下步骤操作。

### 前提条件
- 安装 Hexo
- 克隆 Label Studio GitHub 仓库

### 在本地部署文档
在克隆仓库的 label-studio/docs 目录中，执行以下操作：
1. （首次）安装所需依赖：
```shell
npm install
```
2. 启动 Hexo 服务器：

```shell
hexo serve
```
